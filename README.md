# To. 08또래 칠판

청년부가 고3 친구들(08또래)에게 쓰는 수능 응원 칠판이에요.

- 칠판은 https://ngh3651.github.io/to-08/ 에 있어요. QR이나 링크 속 열쇠가 있어야 열려요.
- 편지는 쓰는 기간 동안 Railway 서버가 받아요.
- 6시간마다 편지 묶음을 잠긴 파일(`snapshot.json`)로 이 저장소에 백업해요. 열쇠가 없으면 아무도 내용을 못 봐요.
- Railway를 해지해도 칠판은 이 백업으로 계속 보여요.

## Railway를 끄기 전에

1. 이 저장소의 Actions 탭 → `snapshot` → Run workflow 를 한 번 눌러요.
2. 초록 체크가 뜨면 백업 끝. 그다음 Railway 프로젝트를 지워도 돼요.
